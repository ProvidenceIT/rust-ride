### Subtask 5.2: Add audio synchronization safeguards (COMPLETED)
- Created AudioTimingConfig struct with configurable timing settings:
  - max_queue_size: Maximum queue items (default: 20)
  - countdown_max_age_ms: Time-critical countdown expiration (default: 500ms)
  - sound_max_age_ms: Regular sound expiration (default: 3000ms)
  - speech_max_age_ms: Voice/TTS expiration (default: 10000ms)
  - min_audio_gap_ms: Minimum gap between audio items (default: 50ms)
  - aggressive_cleanup: Enable automatic cleanup of stale items
  - queue_pressure_threshold: Start dropping low-priority at this % full
- Created QueueStats struct for monitoring queue health:
  - item_count, expired_count, dropped_count
  - low/high priority counts
  - under_pressure flag
  - is_healthy() and status_string() helpers
- Enhanced AudioItem with timing methods:
  - countdown_tone() now has 500ms max_queue_time (time-critical)
  - countdown_tone_with_timing() for custom expiration
  - is_expired(), age_ms(), time_remaining() helpers
  - is_time_critical(), type_description()
  - with_max_queue_time() builder method
- Enhanced AudioEngine trait with new methods:
  - get/set_timing_config()
  - get_queue_stats(), reset_queue_stats()
  - cleanup_expired(), queue_size()
- Updated DefaultAudioEngine with timing safeguards:
  - Aggressive cleanup on queue operations
  - Queue size limits with low-priority dropping
  - Queue pressure handling (drops low-priority items when full)
  - Expired/dropped tracking with counters
  - Event emission for ItemExpired, ItemDropped, QueuePressure
