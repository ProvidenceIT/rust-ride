## Key Patterns Identified
- RollingAverage struct already supports configurable window sizes
- Power uses three_second() and thirty_second() factory methods
- MetricsCalculator processes power through RollingAverage instances
- AggregatedMetrics stores power_3s_avg and power_30s_avg
- MetricType enum in config.rs controls dashboard layout options
- MetricDisplay widget has factory methods for different metric types

## Notes
- RollingAverage uses u16 internally; cadence is u8, so conversion needed
- Spec requests 3s and 10s averages (not 30s like power)
- 3s average should be default display, 10s available for configuration
