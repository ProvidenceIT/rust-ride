# Complete Text-to-Speech Integration

Finish the TTS module implementation to provide voice announcements during workouts. This includes interval changes, target power callouts, motivational cues, and customizable voice settings.

## Rationale
Audio cues are essential for focused training where looking at the screen isn't practical. This is a core feature for serious training that competitors charge subscription fees for.

## User Stories
- As a cyclist doing intervals, I want voice callouts so that I know when to increase or decrease effort without looking at the screen
- As a user, I want to customize the voice settings so that the announcements suit my preferences

## Acceptance Criteria
- [ ] TTS announces interval changes during workouts
- [ ] Target power/cadence callouts work correctly
- [ ] User can select from available system voices
- [ ] Speech rate and volume are configurable
- [ ] TTS works on Windows, macOS, and Linux
