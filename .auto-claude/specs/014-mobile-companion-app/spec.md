# Mobile Companion App

Create a mobile app (iOS/Android) for remote workout control, real-time metrics viewing, and ride history access. Connect to the desktop app over local network.

## Rationale
A mobile companion enables users to mount their phone near the trainer for easy control while keeping the main app on a separate screen. This addresses the gap of no mobile app and improves the overall training experience.

## User Stories
- As a cyclist, I want to control my workout from my phone so that I have easy access to controls
- As a user with a TV display, I want to use my phone for control while the main screen shows the 3D world

## Acceptance Criteria
- [ ] Mobile app connects to desktop app over LAN
- [ ] Real-time metrics display (power, HR, cadence)
- [ ] Basic workout controls (pause, resume, skip)
- [ ] View ride history and statistics
- [ ] Works on iOS and Android
